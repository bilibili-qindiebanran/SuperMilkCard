# IP5306-I2C 通讯协议总结

> 本文档基于英集芯 **IP5306-I2C** 数据手册（V1.2）与寄存器文档（V1.21）整理。
> 适用芯片：IP5306-I2C —— 2.1A 充电 / 2.4A 放电（Boost）移动电源 SoC，带 I2C 控制接口。

---

## 1. 芯片简介

IP5306 是英集芯（Injoinic）推出的 2.1A 充电 / 2.4A 放电移动电源管理 SoC，eSOP8 封装。
本项目的核心目的：**通过 I2C 读取/控制其电源行为**（充电开关、升压开关、轻载关机、按键事件等），并作为硬件伴侣的低功耗电源管理单元。

| 项目               | 说明                                                                               |
| ------------------ | ---------------------------------------------------------------------------------- |
| 充电电流           | 2.1A（VIN 端）                                                                     |
| 放电电流           | 2.4A（Boost 输出）                                                                 |
| 效率               | 充电 92% / 放电 91%                                                                |
| 电池电压范围       | 3.0V ~ 4.4V（支持 4.20/4.30/4.35/4.40V 满电档）                                    |
| 待机电流           | 50µA（VIN=0，VBAT=3.7V）                                                          |
| 静态功耗（不开关） | 100µA                                                                             |
| 封装               | eSOP8L（引脚：VIN / LED1~3 / KEY / BAT / SW / VOUT / PowerPAD）                    |
| LED 指示           | 支持 1/2/3/4 颗 LED 电量显示                                                       |
| I2C                | 从机模式，最高**400kbps**，8 位寄存器，默认从机地址 **0xEA**（8 位写） |

> ⚠️ **重要**：IP5306 **标准品默认不支持 I2C**，需要单独定制 **I2C 版本**，必须按 `IP5306_I2C` 型号申请样品和下单。

## 2. 硬件连接

### 2.1 引脚定义（eSOP8）

| Pin      | 名称 | 说明                     |
| -------- | ---- | ------------------------ |
| 1        | VIN  | DC 5V 输入（充电电源）   |
| 2        | LED1 | 电量 LED1                |
| 3        | LED2 | 电量 LED2                |
| 4        | LED3 | 电量 LED3                |
| 5        | KEY  | 按键输入                 |
| 6        | BAT  | 电池正极                 |
| 7        | SW   | DC-DC 开关节点（接电感） |
| 8        | VOUT | 5V Boost 输出            |
| PowerPAD | —   | 接地（GND）              |

> 说明：数据手册正文中 I2C 的 SCL/SDA 引脚未在 eSOP8 引脚表中单独列出，量产实现中通常复用 **LED1/LED2/LED3** 引脚作 I2C 复用（不同批次的定制版本可能不同，**请以实际样品规格书/丝印为准**）。

### 2.2 I2C 连接示意

```
         VDD（BAT）         ┌─────┐
            │               │IP5306│
            ├──2.2KΩ─┬─────┤SCL  │
            │         │     │     │
            ├──2.2KΩ─┼─────┤SDA  │
            │         │     │     │
  MCU ──SCL─┤         │     │     │
  MCU ──SDA─┘         │     │     │
  MCU ──IRQ────────────────┤IRQ  │
                        └─────┘
```

- SCL / SDA 需各接 **2.2kΩ 上拉**到 VDD。
- **IRQ 引脚**（非必须）：`工作态 = 高电平`，`休眠态 = 高阻`，可用来判断芯片是否在工作。
- **MCU 需要从 BAT 取电**（即电池电压域），I2C 上拉参考电平应与 MCU 侧一致。
- 与 ESP32-S3 接线（本项目默认，可通过 `platformio.ini` 的 `build_flags` 修改）：
  - **GPIO9 = SDA，GPIO10 = SCL**（按实际接线设置）。

## 3. I2C 通讯协议

### 3.1 基本参数

| 参数             | 值                              |
| ---------------- | ------------------------------- |
| 通讯速率         | 最高**400kbps**           |
| 地址宽度         | 8 bit 寄存器地址                |
| 数据宽度         | 8 bit 数据                      |
| 字节序           | **MSB first**             |
| 从机地址（7 位） | `0x75`                        |
| 8 位写地址       | `0xEA`                        |
| 8 位读地址       | `0xEB`                        |
| ACK 校验         | 使能（`ACK_CHECK_EN = true`） |

### 3.2 写时序

```
  ┌────────────────────────────────────────────────────────────┐
  │ Start │ Slave Addr 0xEA │ Reg Addr │ Data │ Stop          │
  └────────────────────────────────────────────────────────────┘
              sACK           sACK       sACK
```

- Master 发 Start → 从机地址 **0xEA**（写）→ 寄存器地址 → 8-bit 数据 → Stop。
- 每个 8-bit 地址/数据后，从机（IP5306）返回 **ACK**（低电平）。
- **必须写满 8 位数据后寄存器才会更新。**
- 例：向寄存器 `0x05` 写入 `0x5A`：`Start [0xEA] [0x05] [0x5A] Stop`。

### 3.3 读时序

```
  ┌────────────────────────────────────────────────────────────────┐
  │ Start │ Addr 0xEA │ Reg Addr │ Restart │ Addr 0xEB │ Data │Stop│
  └────────────────────────────────────────────────────────────────┘
              sACK       sACK                 sACK       mNACK
```

- Master 先发 Start → 写地址 **0xEA** → 寄存器地址 → **Restart** → 读地址 **0xEB** → 从机返回数据。
- 读的最后一个字节，**Master 必须发 NACK（高电平）** 结束读取；若发 ACK 表示继续读。
- 例：读寄存器 `0x05`：`Start [0xEA] [0x05] Restart [0xEB] [0x5A] NACK Stop`。

### 3.4 ACK/NACK 说明（IP5306 作为从机）

| 场景                  | 从机行为                                 |
| --------------------- | ---------------------------------------- |
| Master 写寄存器       | IP5306 返回 ACK（低），表示写入成功      |
| Master 读最后一个字节 | Master 必须返回 NACK（高），否则会有异常 |

> 第 9 个 bit 的 ACK/NACK 由 Master 侧区分读/写操作：读操作结束时 Master 发 NACK，写操作则检查从机返回的 ACK。

## 5. 使用规范与注意事项

1. **读 → 改 → 写**：修改任意寄存器前，先读出原值，对需要修改的 bit 做「与/或」运算后再写回，**确保其他 bit（尤其 Reserved）不被改动**。Reserved 位有特殊控制作用，改动会产生不可预期结果。
2. **Reserved 位禁止改动**。
3. **IP5306 内部没有电压/电流 ADC**，无法直接读取电池电压与电流，需外加带 ADC 的 MCU 管理电量。
4. 建议用 **IRQ 信号**判断工作态：IRQ=1 工作，IRQ=0 待机（高阻）。
5. 状态判断建议：
   - 充电/放电：`0x70` bit3（1 充电，0 放电）；
   - 是否充满：`0x71` bit3（1 充满，0 未充满）。
6. 只有**定制版 IP5306_I2C** 才支持 I2C，标准品不支持。
7. SCL/SDA 需要 2.2kΩ 上拉；I2C 最高 400kbps。

## 6. ESP32 侧使用说明（本项目）

工程：`D:\Projects\SuperMilkCard\ESP32`（PlatformIO + ESP-IDF，ESP32-S3）

### 6.1 接线

| IP5306  | ESP32-S3                   |
| ------- | -------------------------- |
| SDA     | GPIO9（默认）              |
| SCL     | GPIO10（默认）             |
| GND     | GND                        |
| VDD/IRQ | 可选（IRQ 用于工作态检测） |

引脚可通过 `platformio.ini` 的 `build_flags` 修改：

```ini
build_flags =
    -D IP5306_PIN_SDA=9
    -D IP5306_PIN_SCL=10
```

### 6.2 编译 / 烧录 / 监视

```bash
# 进入工程
cd ESP32

# 编译（首次会自动安装 espressif32 平台与 ESP-IDF 工具链，较慢）
pio run

# 烧录
pio run -t upload

# 串口监视（115200）
pio device monitor
```

### 6.3 程序输出示例

```
I (…) ip5306: IP5306 on I2C0 SDA=9 SCL=10 @ 400000 Hz, addr=0x75
I (…) ip5306: I2C device found at 0x75  <-- IP5306
I (…) main: --- factory config registers ---
I (…) main:   SYS_CTL0    (0x00) = 0xBE
...
I (…) main: status: charging=1 full=0 light_load=0 | key: short=0 long=0 double=0
```

### 6.4 驱动 API

| 函数                                         | 说明                                            |
| -------------------------------------------- | ----------------------------------------------- |
| `ip5306_init()`                            | 初始化 I2C 总线（I2C0, 400kHz）并创建设备句柄   |
| `ip5306_read_reg(reg, &val)`               | 读单个寄存器                                    |
| `ip5306_write_reg(reg, val)`               | 整字节写寄存器（慎用，注意 Reserved）           |
| `ip5306_read_modify_write(reg, mask, val)` | **推荐**：读→改→写，只动 mask 覆盖的位  |
| `ip5306_get_status(&st)`                   | 读取电源状态与按键事件（按键读后自动写 1 清零） |
| `ip5306_scan_bus()`                        | 扫描 I2C 总线，打印在线从机地址                 |
